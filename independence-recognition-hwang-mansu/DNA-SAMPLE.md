# 할머니 유전자 시료 — 채취·보관·재사용 메모 (2026-10-13)

상황: 할머니(송동순) 별세, 다니엘병원장례식장. 내일 입관 전 시료 채취.
목적: ① 황유정 친자 증명(제104조 정정 보강 또는 친생자관계존재확인 소송 감정) ② 훗날 형제분들이 쓸 수 있도록 보존.

## 재사용 가능 여부 — 결론

**가능하다. 단, "어디에 무엇이 남는가"를 내일 정해야 한다.**

| 남는 것 | 재사용 | 비고 |
|---|---|---|
| ① 검사기관이 추출해 둔 DNA(추출물) | ○ 가장 좋음 | 기관마다 보관기간 다름(수개월~수년, 유료 연장 가능). **내일 보관기간·연장비용·추가비교 수수료 확인** |
| ② 감정서에 기재된 STR 프로필(유전자형 표) | ○ | 프로필만 있으면 다른 기관에서도 비교 가능. **감정서에 좌위별 유전자형 전부 기재 요청** |
| ③ 남은 원시료(모발·면봉) — 기관 보관 | ○ | 보관 여부·기간 확인 |
| ④ 남은 원시료 — 가족 자체 보관 | △ | 건조 상태면 수년 유지되나, 보관 경위를 가족이 증명해야 해서 증거력은 떨어짐. 그래도 반드시 남겨둘 것 |

## 내일 채취 때 할 일

- **시료를 넉넉히, 종류를 섞어서**: 모근 포함 모발 30~50가닥(종이봉투 2~3개로 분봉) + 구강 면봉 2~4개(입관 전, 가능하면) + 손톱. 구강세포가 모발보다 DNA 양이 많고 안정적임.
- **분봉**: 검사기관 제출용 / 기관 보관 의뢰용 / 가족 보관용으로 나눔. 각 봉투에 성명·채취일시·채취자·입회자 기재.
- **채취 경위 기록**: 영상(얼굴·봉투 밀봉까지), 입회자(장례지도사 + 가족) 이름, 사망진단서 사본 함께 보관. 나중에 "그 시료가 할머니 것"임을 증명하는 유일한 수단.
- **가족 보관분**: 완전 건조 → 종이봉투 → 지퍼백에 실리카겔과 함께 → 서늘하고 건조한 곳(냉장 아님, 비닐 직접 접촉 금지).

## 검사기관에 물어볼 것 (3가지)

1. 추출 DNA·원시료 **보관기간**은 얼마이고, 연장(유료)이 가능한가?
2. 나중에 다른 자녀가 비교를 원하면 **보관 시료로 추가 감정**이 가능한가, 비용은?
3. 감정서에 **STR 좌위별 유전자형**을 전부 기재해 주는가? (기재해 주는 기관을 선택)

## 형제분들이 훗날 쓸 경로

- 1순위: 보관된 할머니 시료/추출물로 직접 부모-자녀 감정 (가장 명확).
- 2순위: 할머니 시료가 없으면 황유정과의 **형제간(sibship) 감정** — 가능하지만 확률적이고 판정력이 떨어짐. 그래서 내일 시료가 중요.

## 법적 위치

- 제104조 간이정정이 2006 공증서로 통하면 DNA는 안 쓸 수도 있음. DNA는 **보험**이다.
- 친생자관계존재확인 소송(피고 검사)으로 가면 사망자 감정은 법원 수검명령 대상이 될 수 없으므로, 이 시료로 받은 사설 감정서가 핵심 증거가 된다. 그래서 채취 경위 기록이 중요.
